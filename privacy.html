Privacy policy

Personal health and training app (private, not a public service) · Last updated 29 October 2026

This app is a private tool built and used by one person, Jamison Power, to track his own food, training, body measurements and recovery. It is not offered to the public. This page explains what it does with data, including data from WHOOP.

What data it uses

  • Food logs, training sets, body weight and measurements, and health records entered by the user.
  • With the user's permission: Apple Health data and WHOOP data (recovery, sleep, cycles and strain, workouts, profile and body measurements).

How it is used

Only to show the user their own data, calculate their targets and trends, and coach their training and nutrition. Data is never sold, shared with advertisers, or used for any other purpose.

Where it is stored

In a private Supabase database in Sydney, Australia, protected by row-level security so each account can see only its own data. WHOOP access tokens are stored encrypted and used only to fetch the user's own WHOOP data.

AI processing

When the user chooses to use the AI coach, the relevant data is sent to Anthropic's Claude, through the user's own Claude account, to answer the user's questions. Anthropic's terms for that account apply.

Your choices

WHOOP can be disconnected at any time in the app's settings or in the WHOOP app, which stops all access. The user can delete any record, or ask for all data to be deleted, at any time.

Contact
